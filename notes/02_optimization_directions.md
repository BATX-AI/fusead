# 优化方向 (目标: 在 AUROC 与经济成本上超越 DyAD)

> 组织方式: 从"对老算法的渐进改进" → "换骨架的中等改动" → "完全不同的范式"。
> 每个方向标注: **攻击的弱点 (W#)**、**预期收益**、**风险/代价**、**改动量**。
> 现成对比: DyAD AUROC **88.6±2.9%**，平均直接成本 **0.085 (10⁴ CNY)**。

---

## A 类 · 对 DyAD 的渐进改进 (低风险、可快速落地、组合增益)

### A1. 训练配方现代化 (W2)
- 把 10 epochs 提到收敛 (50~100 + early-stopping)；`latent_size` 扫 16/32/64/128。
- `SmoothL1` → 试 **Huber/Charbonnier + 通道自适应权重**（温度/电压量纲不同，应分别标准化后等权或学习权重）。
- KL 退火换 **cyclical annealing**（缓解 posterior collapse），加 **free-bits**。
- **预期**: AUROC +1~3%。**代价**: 几乎零，调参而已。**改动量**: 极小。

### A2. 修复里程归一化 + 扩展弱监督 (W3, W6)
- 里程归一化改成**全训练集分位数 (robust scaler)**，而非前 50 样本 min/max。
- 弱监督头从"只预测里程"扩成**多任务**: 里程 + 充电起止 SOC + 环境温度 + 车龄 + 充电桩功率档位。让隐空间编码更多"正常变异"的协变量 → 减少把"正常的罕见工况"误判为异常。
- **预期**: AUROC +1~2%、FPR 明显下降。**代价**: 需元数据字段(数据集大概率有)。**改动量**: 小。

### A3. 多信号异常分数融合 (W5, W9)
不再只用重建误差，构造**异常分数向量**再融合：
- `s1` = 系统响应预测误差 (原始信号)
- `s2` = **隐空间密度**: 在正常车 `μ` 上拟合 GMM/normalizing flow，取负对数似然
- `s3` = **预测不确定性**: 用 MC-dropout / 深度集成得到响应预测方差，误差/方差 (类 Mahalanobis) 做标准化残差
- `s4` = **物理残差** (见 C2)
- 融合: 先无监督标准化，再用极少量故障车做 **logistic / Platt 校准**学权重。
- **预期**: AUROC +2~4%，且产出**标定后的概率**直接服务经济阈值。**代价**: 中。**改动量**: 中。

### A4. 可学习的鲁棒评分替代 τ,p 网格 (W4)
把"片段误差 → 车级分数"的硬规则换成**可微聚合**：
- **注意力池化 / Set Transformer / DeepSets** 把一辆车的片段误差集合映射到车级 logit；
- 或 **可微 top-k (软分位数)**，端到端学 `p`。
- **预期**: 去掉脆弱超参，AUROC +1~2%、跨厂商更稳。**代价**: 中。**改动量**: 中。

## B 类 · 换时序骨架 / 学习范式 (中风险、中收益)

### B1. 骨架升级: GRU → TCN / Transformer / **SSM(Mamba)** (W2, W7)
- 充电片段 128 步、且关心长程产热/极化趋势，**因果 TCN** 或 **状态空间模型 (S4/Mamba)** 在长序列上更稳更快。
- 保留"动态自编码"的输入/响应拆分思想，只换 encoder/decoder 主干。
- **预期**: AUROC +2~4%；推理更快(利于边缘部署)。**代价**: 实现+调参。**改动量**: 中。

### B2. 把"片段独立"升级为"车级序列建模" (W7)
- 同一辆车的多个充电片段按时间排成**序列的序列**，用层级模型 (片段编码器 + 车级时序聚合) 捕捉**老化轨迹**与突变点。
- 异常 = 轨迹偏离正常老化流形 / 出现 changepoint。
- **预期**: 对"缓慢劣化型"故障显著提升召回。**代价**: 数据需按车-时间重组。**改动量**: 中大。

### B3. 对比 / 度量学习利用 55 辆故障车 (W6)
- **PU learning (Positive-Unlabeled)**: 故障车=正、其余=未标，训练 PU 分类器纠正单类偏差。
- **Supervised contrastive / triplet**: 拉近正常、推远故障的车级表征；故障样本虽少但提供强方向信号。
- **Deep SAD** (半监督 SVDD): 在 DyAD 隐空间上加"故障样本远离球心"的监督项。
- **预期**: AUROC +3~5%（这是论文明显留白）。**代价**: 需防过拟合 55 个正例(强正则/数据增强)。**改动量**: 中。

### B4. 跨厂商统一模型 + 域适应 (W1)
- 一个共享主干 + **brand-specific 适配头/FiLM 条件**，用全部 70 万片段联合训练；小样本 brand 借力大样本 brand。
- 域对齐: CORAL / DANN / 域归一化，处理三厂商传感器/化学差异。
- **预期**: 小 brand (brand3) AUROC 大幅提升、整体方差 ↓（DyAD 方差 ±2.9 有压缩空间）。**代价**: 列对齐工程。**改动量**: 中。

### B5. 数据增强与自监督预训练 (W2)
- 充电片段做**掩码重建 / 对比 (TS2Vec, TF-C)** 自监督预训练，再微调异常头；尤其救小样本 brand。
- 物理一致的增强: 时间扭曲、SOC 段裁剪、温漂注入。
- **预期**: AUROC +1~3%，鲁棒性↑。**代价**: 预训练算力。**改动量**: 中。

## C 类 · 完全不同的范式 (高风险、高上限、强论文卖点)

### C1. 条件生成式预测 + 似然异常 (扩散 / 流模型)
- 用**条件扩散模型**或 **conditional normalizing flow** 学 `p(系统响应 | 系统输入)` 的完整分布(而非点估计)。
- 异常分数 = 观测响应在该条件分布下的**负对数似然 / 重建似然比**。比 MSE 误差信息量大、自带不确定性。
- **预期**: AUROC +3~6% 且天然标定。**代价**: 训练/推理较重。**改动量**: 大。

### C2. 物理信息混合模型 (PINN / 灰盒) (W8)
- 在解码器里嵌入**等效电路模型 (ECM: R0+RC) 或简化电化学/产热方程**作为结构先验，神经网络只学参数与残差。
- 异常分数 = **物理残差** + 拟合出的物理参数(内阻 R0、极化、产热系数)漂移。
- 卖点: **可解释**(直接给出"内阻异常升高""产热偏大")，论文 Discussion 明确点名希望估计 capacity/内阻。
- **预期**: AUROC 与 DyAD 相当或更高，但**可解释性+早期预警提前量**是降维打击。**代价**: 物理建模门槛。**改动量**: 大。

### C3. 直接优化经济成本的端到端决策 (W9 + 成本模型)
- 不再"先 AUROC 后调阈值"，而是把式(6)的**期望成本作为可微目标**(或用 ROC 凸包 + 代价敏感学习)直接训练。
- 输出**标定概率**，按 `p, c_f, c_t` 解析求每区域最优阈值。
- **预期**: 即使 AUROC 持平，**平均直接成本可再降**(论文最看重的就是省钱) → 直接打在最强指标上。**代价**: 需可靠概率标定。**改动量**: 中。

### C4. 图/关系建模: 单体-单体、车-车 (W5, W7)
- 单体电压/温度之间的**空间关系图** (类 GDN 思路但放进动态自编码框架)，捕捉"单体不一致"这一关键析锂/短路前兆。
- 车队级图: 同型号车互为参照做相对异常 (relative anomaly)。
- **预期**: 对"单体不一致型"故障召回↑。**代价**: 需单体级数据(数据集含 max/min single volt，至少能做粗粒度)。**改动量**: 中。

### C5. 基础模型 / 时序大模型 zero-few-shot (W1, W2)
- 用时序基础模型 (MOMENT / Chronos / Time-MoE 等) 抽通用表征，少样本微调异常头；探索跨厂商零样本迁移。
- **预期**: 工程量小却可能逼近 SOTA，适合做"强基线 + 新意"。**代价**: 依赖外部大模型权重。**改动量**: 中。

## 方向优先级矩阵 (收益 vs 代价)

| 方向 | 攻击弱点 | 预期 AUROC 增益 | 经济成本影响 | 改动量 | 优先级 |
|---|---|---|---|---|---|
| A1 训练配方 | W2 | +1~3% | 小 | 极小 | ★★★ 立即 |
| A2 归一化+多任务弱监督 | W3,W6 | +1~2% | FPR↓ | 小 | ★★★ 立即 |
| A3 多信号融合+标定 | W5,W9 | +2~4% | **大** | 中 | ★★★ |
| A4 可学习评分 | W4 | +1~2% | 中 | 中 | ★★ |
| B3 PU/对比利用故障车 | W6 | +3~5% | 中 | 中 | ★★★ |
| B4 跨厂商统一+域适应 | W1 | 方差↓, 小brand↑ | 中 | 中 | ★★★ |
| B1 SSM/Transformer 骨架 | W2,W7 | +2~4% | 小 | 中 | ★★ |
| C1 扩散/流 似然异常 | W5,W9 | +3~6% | 大 | 大 | ★★ 探索 |
| C2 物理混合(PINN) | W8 | 持平~↑ + 可解释 | 中 | 大 | ★★ 差异化 |
| C3 端到端成本优化 | 成本 | 持平 | **直降成本** | 中 | ★★★ |

**组合拳建议(非互斥)**: `A1+A2+A3+A4` 作为"增强版 DyAD"基线，叠加 `B3(故障车监督) + B4(跨厂商)`，决策层套 `C3(成本优化)`；C1/C2 作为两条高上限的差异化研究线并行探索。
